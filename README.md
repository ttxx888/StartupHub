# 启动台 StartupHub

中文 Windows 桌面启动与服务管理器。统一管理网页、本地文件、桌面程序、一次性脚本和本地网页服务，提供 WPF 界面、系统托盘、登录自启与 CLI。

界面采用暖米白与陶土橙主题，支持跟随系统、浅色和深色外观，在"设置与配置"中选择后立即生效。侧栏可通过顶部箭头或 Ctrl+B 折叠并记住状态；右侧详情可收起，小窗口通过"显示详情"打开覆盖面板，按 Esc 收起。

## 功能概览

- 六种任务类型：网址、本地文件、桌面程序、网络登录与检查、一次性脚本、本地网页服务
- 系统托盘常驻。关闭窗口收进托盘；右键托盘退出后，已启动的服务继续运行并写日志
- 登录自启清单（当前用户的 Windows 计划任务），支持前置依赖、启动延迟与端口/健康检查就绪等待
- 拖拽导入桌面图标或资源管理器文件，单项进入预填表单、多项进入批量预览；`.lnk`/`.url` 自动识别类型
- "发现本地网页"扫描本机监听端口和本地 HTML 文件，选择后一键加入清单
- 列表内拖动排序、拖入侧栏分类、多选批量管理与删除；Ctrl+N 添加、Ctrl+E 编辑、Ctrl+F 搜索、F5 刷新、双击启动
- CLI 与界面共用任务执行和配置逻辑，通过命名管道控制单实例，`--json` 返回结构化结果

## 打开与使用

双击 `StartupHub.exe` 或其桌面快捷方式。以下示例假设程序放在 `C:\StartupHub`，实际路径以你的安装位置为准。

- 普通打开只显示管理界面。点击"启动自启项"才会手动执行清单。
- 勾选任务左侧"自启"，即可将其加入登录执行清单。总开关在"设置与配置"。
- 登录 Windows 后在托盘启动并执行清单；服务默认后台运行，是否打开页面在每项编辑页设置。
- 选中任务后可启动、停止、重启、打开页面、编辑、复制、调整顺序和查看日志。
- "发现本地网页"扫描当前监听端口，选择后添加，不会启动被发现的程序。
- 按住 Ctrl 点选多个任务，按住 Shift 连续选择；列表获得焦点后 Ctrl+A 选择当前筛选下的可见任务。
- "删除所选…"会列出删除清单及需要解除的前置依赖，确认后只删除清单条目并解除对应依赖，保留项目文件和运行进程。
- 按住任务左侧"⋮"或名称区域拖动可调整顺序；将任务拖到左侧分类可移动分类；分类本身也可拖动排序，橙色插入线指示位置。拖到列表边缘自动滚动，按 Esc 取消。

## 添加任务

在"入口"选择程序或文件，也可直接粘贴 HTTP/HTTPS 地址，类型和名称会自动填写。名称可修改；分类默认使用当前具体分类，新任务默认不自启。入口框支持拖入单个文件。

程序和文档快捷方式沿用原 `.lnk` 文件启动，保留原有参数与工作目录；`.url` 识别为网址。删除、移动快捷方式或其目标失效后，会显示"入口缺失"。

| 类型 | 填写方式 |
|---|---|
| 网址 | 填写 HTTP/HTTPS 地址，以默认浏览器打开 |
| 本地文件 | 填写 HTML、文档或目录路径，以系统关联程序打开 |
| 桌面程序 | 填写 EXE/LNK，按需填写参数和工作目录；支持 Windows 包应用标识 |
| 网络登录与检查 | 填写认证入口、代理和目标检查地址；直连检查默认读取 Windows 连接测试配置 |
| 一次性脚本 | 填写 PS1/BAT/CMD/PY/JS，或指定解释器并单独填写脚本路径 |
| 本地网页服务 | 填写程序、脚本、参数、工作目录；高级设置中填写端口、健康检查和依赖 |

参数表格每行一个参数，不添加外层引号。例如 `--port` 和 `3000` 分别占一行。Python 项目建议指定其虚拟环境中的解释器。PS1 使用本机 Windows PowerShell 5.1；包含中文正文的脚本应保存为 UTF-8 BOM 或该解释器支持的编码。

## 发现本地网页

点击侧栏"发现本地网页"，扫描期间在窗口底部显示已检查数量。结果同时包含正在运行的网页服务及本地 HTML 文件：服务按实际 IPv4、IPv6 和网卡监听地址探测 HTTP/HTTPS；HTML 文件显示文件路径，添加后作为"本地文件"任务打开。默认不自启。

单选后可"打开预览"；支持 Ctrl/Shift 多选和全选，选择分类后添加。已有网址按完整地址排除重复；本机环回地址统一比较。展开"未加入结果的入口"可查看证书问题、服务未监听、非网页、空响应等原因。HTTPS 证书正常校验；JSON API、空响应、错误响应和桌面程序内部页面不作为可添加网页。CLI `discover` 返回相同结果，`discover --details` 同时返回页面与问题列表。

## 登录自启与网络检查

登录总开关管理当前用户的登录计划任务（`--autostart --tray`）。同一次 Windows 登录的重复通知只执行一次；普通打开不执行清单，手动"启动自启项"与单项启动随时可重试。

网络任务链支持：前置桌面程序（如本地代理）进程与端口就绪 → 直连 Windows 连接测试 → 经代理检查目标 HTTPS 通路。HTTP 401/403 等认证或访问限制响应代表目标通路可达，不代表账号已登录。需要认证时，用默认浏览器的现有配置打开认证入口，只尝试调用一次"登录"按钮，不读取账号密码；20 秒内无法调用则提示手动登录。网络阶段最多 300 秒，每 3 秒检查一次，单次请求最多 5 秒。

桌面程序可填写 Windows 包应用标识，或启用"等待桌面程序与端口就绪"；高级设置中可选择前置任务及延迟。日志文件超过 5 MB 后在下次启动时保留一份 `.previous`。

## CLI 控制

CLI 与界面共用任务执行和配置逻辑，通过当前用户的命名管道连接单实例。首次使用 CLI 会在托盘启动管理器，不执行自启清单。

```powershell
$hub = 'C:\StartupHub\app\startuphub-cli.exe'
& $hub --help
& $hub --json tasks list
& $hub tasks show '示例服务'
& $hub run start '示例服务' --background
& $hub logs show '示例服务'
& $hub run stop '示例服务'
& $hub tasks autostart '示例服务' on
& $hub tasks move '示例任务一' before '示例任务二'
& $hub tasks group '示例任务一' '直接打开'
& $hub groups move '直接打开' before '常用服务'
& $hub ui show
& $hub ui exit
```

命令可使用名称或稳定 ID，名称重复时使用 ID。`--json` 返回 `{ok,data,error}`，退出码 0 表示成功，1 表示操作失败，2 表示参数错误。

添加任务示例——将下列内容保存为 JSON 文件，再执行 `tasks add --file 文件路径`：

```json
{
  "Name": "示例服务",
  "Group": "开发网页",
  "Kind": "Service",
  "Path": "C:\\Program Files\\nodejs\\node.exe",
  "Script": "C:\\projects\\demo\\server.js",
  "Arguments": ["--port", "8080"],
  "WorkingDir": "C:\\projects\\demo",
  "Url": "http://127.0.0.1:8080/",
  "CheckUrl": "http://127.0.0.1:8080/health",
  "Port": 8080,
  "WaitSeconds": 30,
  "AutoStart": false,
  "OpenPageOnAutoStart": false
}
```

`tasks update <ID> --file patch.json` 合并修改字段；`config export/import` 导出和导入完整配置；`startup status/enable/disable` 管理登录自启；`ui snapshot --output 文件.png --scale 1.5` 导出界面渲染。

## 构建与数据

| 目录 | 内容 |
|---|---|
| `app` | 可双击运行的发布程序及 CLI（构建产物） |
| `data` | config.json、state.json、日志和导入前备份（运行数据） |
| `src` | Core、WPF App、CLI 源码 |
| `tests` / `ui-tests` | 验收测试 |

开发构建：运行 `build.ps1`（需要 .NET 10 SDK）；运行 `verify.ps1` 执行核心验收。更新时退出管理器，再替换 `app` 内的发布文件，保留同级 `data` 目录。运行程序只需 .NET 10 Desktop Runtime。
